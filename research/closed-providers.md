## 2. Retell AI (for the kids' bot)

- **Seven voice providers** (docs): Platform voices (auto-routed), MiniMax (`speech-02-turbo`, `speech-2.8-turbo`), Cartesia (`sonic-3`, `sonic-3-latest`, `sonic-3.5`; **no 3.6 listed**), Inworld (`inworld-tts-2`, `-flash`), Fish (`s1`, `s2-pro`, `s2.1-pro`), ElevenLabs (`eleven_flash_v2`, `eleven_flash_v2_5`, `eleven_multilingual_v2`, `eleven_v3`), OpenAI (`tts-1`, `gpt-4o-mini-tts`). The Hindi column is ✓ for every provider. **Gemini, Sarvam, Smallest, Hume and Azure TTS are not offered.**
- **Price per minute (retellai.com/pricing):** Retell Voice Infra $0.055, plus TTS: Platform, MiniMax, Fish, Cartesia, OpenAI and Inworld are each **$0.015**; **ElevenLabs $0.040**.
- **Latency:** the docs give no millisecond figures. They say only that Cartesia has "among the lowest synthesis latency of any provider in published benchmarks" and that `inworld-tts-2-flash` "trades some quality for lower latency". Expressive Mode (emotion tags) works **only on platform voices**. The `voice_emotion` field works only on Cartesia and MiniMax.

## 4. Surprises / contradictions

1. **Neither arena tests Hindi.** HF's prompts are "English-only". Retell's docs describe AA as "English only". So the leaderboard ranks tell you nothing about Hindi quality. You need your own Hindi listening test.
2. **Fish bills per UTF-8 byte, not per character.** Devanagari takes about 2.5× more bytes, so Hindi really costs about $38/1M characters, not $15. The "free for every developer" S2.1 Pro API is a separate model string (`s2.1-pro-free`). It has had four end dates so far (24 Jul → end of Jul → 31 Aug → 30 Nov 2026), comes with no SLA, and your requests "may be used to improve model quality".
3. **The "#1 on Artificial Analysis" claims conflict.** Inworld's pricing page says TTS-2 is #1, Alibaba's blog says Qwen Plus is #1, and Retell says Inworld is first. Today AA shows **Cartesia Sonic 3.6** at #1 and Inworld at #4.
4. **Fish's blog says Gemini TTS has "zero free usage".** Google's own pricing page shows a free tier ("Free of charge") for both 3.8 TTS models. The catch is that Google uses free-tier data to improve its products.
5. **Gemini 3.8 TTS is one day old and its price doubles on 1 Jan 2027** ($9 → $18 per 1M audio tokens).
6. **Cartesia's emotion tags are English-only**, and Inworld's steering instructions must be written in English. For Hindi drama, the controls that are documented to work with Hindi text are ElevenLabs v3, Fish, Gemini, MiniMax, OpenAI and Azure MAI-Voice-2 styles.
7. **Sarvam's docs warn against romanised Hinglish.** They say "Romanised Indic input degrades quality" and recommend Devanagari with English loanwords. Cartesia and Smallest explicitly support romanised or code-switched Hindi.
8. **Speechify's Simba 3.2 (#5) and Alibaba's Qwen Plus (#3) don't do Hindi.**
9. **Retell's page contradicts Inworld.** Retell says Inworld has "15 languages". Inworld's docs say 200+, with Hindi in Tier 1.
10. **OpenAI custom voices and xAI's cloning API aren't self-serve.** OpenAI's are sales-gated, and xAI's clone API is Enterprise-only.
11. **Azure quietly ships emotional Hindi HD voices** (MAI-Voice-2, e.g. Dhruv, with styles including whispering, sad and fearful) at $22/1M. That's cheaper than ElevenLabs v3.
